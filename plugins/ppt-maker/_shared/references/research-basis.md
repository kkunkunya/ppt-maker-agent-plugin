# Research Basis

This plugin starts from a 2026-04-28 survey of PPT-related agent resources.

Key conclusions:

- `PPT-Design-Prompt` is a slide-image prompt and brand preset resource, not a deck generator.
- `guizang-ppt-skill` is strong for single-file HTML showcase decks, not editable PPTX.
- `ian-handdrawn-ppt` is strong for raster handdrawn explainer pages, not editable PPTX.
- Editable PPTX and fixed-template safe fill require separate deterministic tooling and verification.

The first version of this plugin intentionally captures routing and workflow judgment. Deterministic scripts should be added only after a real sample deck/template proves the workflow.
